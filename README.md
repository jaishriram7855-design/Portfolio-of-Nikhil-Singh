# Nikhil Singh – Portfolio

```
npm run build    # production build in dist/
```
Edit all content in `src/data/content.js` (GitHub/live links, socials). Replace `public/Nikhil_Singh_CV.pdf` and `public/profile.jpeg` to update the resume/photo.
